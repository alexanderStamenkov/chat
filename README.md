# 💬 Chat App

A real-time chat application built using vanilla JavaScript, HTML5, CSS3, **Vite**, and **Supabase**.

## 🚀 Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Bundler:** Vite v5
- **Backend & Database:** Supabase (User Authentication & Realtime Database)

## 🛠️ Local Development Setup

1. Clone the repository and navigate to the project root:

```bash
   cd Chat
```
